# AI Agent Migration Guide: CustomTkinter to PySide6 + QML (Qt Quick)

> **Purpose for AI Agent**: This document provides exact instructions, architectural blueprints, widget mapping rules, and code patterns required to refactor an existing Python application from **CustomTkinter** to **PySide6 (Qt 6) with QML (Qt Quick)**. Follow these instructions step-by-step to achieve a decoupled, modern, hardware-accelerated desktop application.

---

## 1. Core Architectural Shift

CustomTkinter tightly couples Python backend logic with UI component declaration (e.g., `ctk.CTkButton(master, text="...").pack()`). 

In contrast, **PySide6 + QML** enforces a strict **Model-View-ViewModel (MVVM)** or **Controller-View** separation:
* **Frontend (View)**: Defined entirely in declarative `.qml` files (HTML/CSS-like syntax with JavaScript expressions for visual behavior). Renders via hardware acceleration (Vulkan, DirectX, Metal, or OpenGL).
* **Backend (Controller/ViewModel)**: Written in pure Python, inheriting from `QObject`. Uses Qt **Signals**, **Slots**, and **Properties** (`Property`) to exchange state and events with QML.

```text
+-------------------------------------------------------+
|                    QML UI FRONTEND                    |
|  (Main.qml, Components/*.qml, Animations, Styling)   |
+-------------------------------------------------------+
                           ^
     Property Bindings     |     User Events / Actions
     & Signal Handlers     |     (Slots / Python Methods)
                           v
+-------------------------------------------------------+
|                  PYTHON BACKEND (PySide6)             |
|  (QObject Bridge, Thread Pools, Business Logic, APIs) |
+-------------------------------------------------------+
```

## 4. Widget Mapping Matrix (CustomTkinter -> QML)

Use this table when translating UI components from Python `ctk` code to QML markup:

| CustomTkinter Widget (`ctk.CTk...`) | Qt Quick / QML Primitive | Recommended QML Controls 2 Component |
| --- | --- | --- |
| `CTk` / `CTkToplevel` | `ApplicationWindow` / `Window` | `import QtQuick.Controls` -> `ApplicationWindow` |
| `CTkFrame` | `Rectangle` or `Pane` | `Rectangle { color: "#18181b"; radius: 8 }` |
| `CTkLabel` | `Text` or `Label` | `Label { text: "..."; font.pixelSize: 14 }` |
| `CTkButton` | `Button` | `Button { text: "..."; background: Rectangle {...} }` |
| `CTkEntry` | `TextField` | `TextField { placeholderText: "..." }` |
| `CTkTextbox` | `TextArea` / `Flickable` | `ScrollView { TextArea { ... } }` |
| `CTkCheckBox` | `CheckBox` | `CheckBox { text: "..." }` |
| `CTkSwitch` | `Switch` | `Switch { ... }` |
| `CTkOptionMenu` / `CTkComboBox` | `ComboBox` | `ComboBox { model: ["Opt 1", "Opt 2"] }` |

## 5. Python-to-QML Bridge Pattern

Every dynamic property, button click, or update must pass through a Python `QObject` class.

### 5.1 Python Backend Controller (`backend/bridge.py`)

```python
import sys
from PySide6.QtCore import QObject, Signal, Slot, Property

class AppBridge(QObject):
    """Bridge class providing state and actions to QML."""
    
    # 1. Declare Signals for State Changes
    usernameChanged = Signal(str)
    statusMessageChanged = Signal(str)
    isLoadingChanged = Signal(bool)

    def __init__(self, parent=None):
        super().__init__(parent)
        self._username = "Guest User"
        self._status_message = "Ready"
        self._is_loading = False

    # 2. Define Qt Properties for Two-Way / One-Way QML Binding
    @Property(str, notify=usernameChanged)
    def username(self):
        return self._username

    @username.setter
    def username(self, value):
        if self._username != value:
            self._username = value
            self.usernameChanged.emit(self._username)

    @Property(str, notify=statusMessageChanged)
    def statusMessage(self):
        return self._status_message

    @Property(bool, notify=isLoadingChanged)
    def isLoading(self):
        return self._is_loading

    # 3. Expose Methods (Slots) to QML
    @Slot(str, str)
    def handleLogin(self, username, password):
        """Called directly from QML button click."""
        self._is_loading = True
        self.isLoadingChanged.emit(True)
        self._status_message = "Authenticating..."
        self.statusMessageChanged.emit(self._status_message)
        
        # Simulate processing or invoke background worker
        if username and password:
            self._username = username
            self.usernameChanged.emit(self._username)
            self._status_message = "Login successful!"
        else:
            self._status_message = "Invalid credentials."
            
        self._is_loading = False
        self.isLoadingChanged.emit(False)
        self.statusMessageChanged.emit(self._status_message)
```

## 6. QML Frontend Architecture

### 6.1 Entry Point (`main.py`)

```python
import sys
import os
from PySide6.QtGui import QGuiApplication
from PySide6.QtQml import QQmlApplicationEngine
from PySide6.QtCore import QUrl
from backend.bridge import AppBridge

def main():
    app = QGuiApplication(sys.argv)
    
    # Optional: Enable High-DPI and modern Quick Controls style
    os.environ["QT_QUICK_CONTROLS_STYLE"] = "Basic"

    engine = QQmlApplicationEngine()
    
    # Instantiate Backend Bridge
    bridge = AppBridge()
    
    # Expose Bridge to QML Context
    engine.rootContext().setContextProperty("appBridge", bridge)

    # Load Main QML File
    qml_file = os.path.join(os.path.dirname(__file__), "ui/qml/Main.qml")
    engine.load(QUrl.fromLocalFile(qml_file))

    if not engine.rootObjects():
        sys.exit(-1)

    sys.exit(app.exec())

if __name__ == "__main__":
    main()
```

## 7. Migration Step-by-Step Execution Plan

When converting a legacy CustomTkinter project, perform the migration in these strict phases:

### Phase 1: Business Logic Extraction

1. Search all CustomTkinter code for Python calculations, API calls, file operations, or data queries.
2. Move all business logic out of Tkinter callbacks (`command=self.my_func`) into dedicated Python service classes or `backend/bridge.py` slots.
3. Ensure no `tkinter` or `customtkinter` imports remain inside business logic modules.

### Phase 2: QML UI Reconstruction

1. Replace top-level `CTk()` or `CTkToplevel()` windows with `ApplicationWindow` or `Window` in QML.
2. Re-create layout structures using `RowLayout`, `ColumnLayout`, `GridLayout`, or `StackView` instead of Tkinter `.pack()` or `.grid()`.
3. Wrap interactive widgets in custom reusable QML components (`.qml` files in `ui/qml/components/`).

### Phase 3: State & Event Binding

1. Map variables previously tracked via `ctk.StringVar()` or `ctk.IntVar()` to `@Property` variables in `AppBridge`.
2. Connect UI events (e.g., `onClicked`, `onTextChanged`, `onValueChanged`) directly to `@Slot` methods on `appBridge`.
3. Use QML property bindings (`text: appBridge.username`) for automatic multi-directional updates.

### Phase 4: Styling & Hardware-Accelerated Polish

1. Apply Zinc/Slate 2026 dark-mode color scheme (`#09090b` base, `#18181b` card surfaces, `#27272a` subtle borders).
2. Add micro-interactions: add `Behavior on color` or `Behavior on opacity` for fluid 60fps animations.
3. Replace raster image assets with scalable `.svg` vector icons in `Image` elements.

## 8. Threading & Asynchronous Operations

**Never block the QML main thread.** If your app performs network requests, heavy calculations, or file processing:

```python
from PySide6.QtCore import QRunnable, QThreadPool, Slot

class Worker(QRunnable):
    def __init__(self, fn, *args, **kwargs):
        super().__init__()
        self.fn = fn
        self.args = args
        self.kwargs = kwargs

    @Slot()
    def run(self):
        self.fn(*self.args, **self.kwargs)

# Usage inside AppBridge:
class AppBridge(QObject):
    def __init__(self):
        super().__init__()
        self.threadpool = QThreadPool()

    @Slot()
    def startHeavyTask(self):
        worker = Worker(self._heavy_task_impl)
        self.threadpool.start(worker)

    def _heavy_task_impl(self):
        # Time-consuming processing runs in background thread
        pass
```
