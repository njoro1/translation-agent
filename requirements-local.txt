# Optional tooling to RUN a local llama.cpp server on your machine.
#
# The app now bundles a CPU-only `llama-server` (in `vendor/llama/`) and can
# auto-start it against a GGUF you supply, so you usually do NOT need this file.
# Install it only if you prefer the convenience of `python -m llama_cpp.server` to
# serve your GGUF manually; any OpenAI-compatible llama.cpp build works.
#
# NOTE: the default target model is Hy-MT2-1.8B-Q8_0.gguf, a Q8_0 quantization
# that is a standard llama.cpp format supported by the bundled/recent llama-server.
# If translations come out as garbage, make sure you're using a recent
# llama-cpp-python build (or the bundled `llama-server`).
llama-cpp-python[server]
