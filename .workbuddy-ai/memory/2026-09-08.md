### Top findings (P0)
1. **U-01** Review tab is read-only — `CuePreviewTable.qml:223` only copies; no edit/save.
   Core job ("ship a correct subtitle") cannot finish in-app.
2. **U-02** Failures show only "Finished with errors (exit N). See the log." and the
   LogDrawer is collapsed at 34 px by default (`bridge.py::_on_finished`).
3. **U-03a** `ReadinessChecklist.qml:30-32` `_outputReady()` returns hardcoded `true`
   → permanently green row that trains users to ignore the checklist.
4. **U-04** Two language controls: header `Lang` → `--source-lang`; Run-tab `ASR lang` →
   `--asr-lang`. Confirmed in `backend/bridge.py::_build_run_config` (local modes emit both).
5. **U-06** `QualityPanel.qml:34` `appBridge.qualityAverageCps.toFixed(1)` unguarded →
   silent QML binding failure.
6. **U-23** `main.py:33` uses `logging` but never imports it → NameError on the bundled-font
   failure path (app fails to start where CJK fallback matters most).
