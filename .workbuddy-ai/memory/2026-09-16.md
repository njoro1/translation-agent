coding implementation of the project as of now. Be thorough."

Both root docs (`AGENT_DOCUMENTATION.md`, `README.md`) were verified claim-by-claim
against the working tree and rewritten where they had drifted. The drift was

### Method that worked (reuse this next time)

1. Read both docs in full, then diff their claims against the tree rather than
   trusting either one.
2. Inventory in parallel: three read-only Explore agents — one for `ui/qml/**`
   (pages + 34 components + `Theme.qml` + which `appBridge.*` members QML actually
   touches), one for `backend/**` (signals/properties/slots/`_PERSISTED`/failure
   table/`_build_run_config`), one for `src/**` (per-module signatures, constants,
   env vars). Do the CLI (`translate.py` argparse + `main()`) and the build script
   by hand — they are the two places the docs are most often wrong.
3. Verify the surprising claims yourself with targeted greps. Three of the four
   real defects below came from a single `grep -rn`.
4. Run the suite for the real test count instead of repeating the documented one.

### Real defects found while verifying (documented in §9, none fixed here)

1. **`saveWindowState` has no `@Slot`** (`backend/bridge.py:3481`) yet
   `ui/qml/Main.qml:108` calls it from `onClosing` → window geometry never
   persists. Highest-value fix: add `@Slot(str)`.
2. **`assets/fonts` is not bundled** — `main.py::_load_bundled_fonts()` reads
   `<resource>/assets/fonts`, `build_exe.bat` never adds `assets`, and
   `dist/TranslationAgent/_internal/assets/` does not exist. Packaged app falls
   back to system fonts. Fix: `--add-data "assets;assets"`.
3. **`SettingsPage.qml:242` tests `"local_asr_cloud_translate"`**, but the bridge
   only emits `"local_cloud"` → the mode chip says "YouTube Cloud" in Local Cloud
   mode.
4. **`HY_MT2_MAX_BATCH_*` env vars are inert** — `src/translate.py:277-284` reads
   them into constants nothing reads. Real budgets live in
   `translation_windows.HY_MT2_MAX_*`.

Also noted: `CueFilterProxyModel.filterMode`/`searchText` are plain Python
`@property` but are written from QML; `tools/screenshot_ui.py` looks up
`objectName`s (`mainTabs`, `advancedDrawer`, `presetPicker`) that no longer exist;
`AppCheckBox.qml` is registered but never instantiated; the `_FAILURE_PATTERNS`
comment claims `ASR_MODEL` precedes `SOURCE_UNAVAILABLE` but the table has it 8th;
`_asr_max_segment_ms` defaults to `"6000"` in `_PERSISTED` but `"7000"` in
`__init__`.
